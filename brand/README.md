# Chalk brand assets

`chalk-original.png` is an unchanged copy of the supplied logo. The transparent wordmark and symbol in `docs/assets/`, `website/content/assets/`, and `src/chalk/assets/` are derived from that image: the near-white background is made transparent, the artwork is cropped, and the result is resized. The light symbol is used on dark headers. The favicon uses the symbol with padding to preserve its proportions.
