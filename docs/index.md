# Chalk documentation

**Chalk — RL environments for coding and mathematical reasoning.**

Chalk provides a framework for writing tasks in Python, running an agent with tools in an isolated runtime, scoring its work, and recording a transcript. The templates include a small Python example, an experimental language-toolchains template, and an experimental Lean maths task.
